# 📱 TERMUX SETUP (ANDROID)

## ⚙️ Install Requirements

```bash
pkg update && pkg upgrade -y
pkg install nodejs git -y
```

---

## 📥 Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/tensura-anime-bot.git
cd tensura-anime-bot
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## 🚀 Run Bot

```bash
node index.js
```

---

## ⚠️ Termux Notes

- Keep Termux open while bot is running  
- Enable wake lock:
```bash
termux-wake-lock
```

---

# 🐧 LINUX SETUP (UBUNTU / DEBIAN / ARCH / VPS)

## ⚙️ Install Node.js & Git

### Ubuntu / Debian
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install nodejs npm git -y
```

### Arch Linux
```bash
sudo pacman -S nodejs npm git --noconfirm
```

---

## 📥 Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/tensura-anime-bot.git
cd tensura-anime-bot
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## 🚀 Start Bot

```bash
node index.js
```

---

## ⚡ 24/7 RUN (PM2)

```bash
npm install -g pm2
pm2 start index.js --name tensura-bot
pm2 save
pm2 startup
```
