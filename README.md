# Tensura Anime Bot

Anime-themed WhatsApp bot inspired by Rimuru Tempest.

## Features

- !ping
- !waifu
- !rimuru
- !animequote
- !joke
- !rules
- !tagall

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/tensura-anime-bot.git
cd tensura-anime-bot
npm install
npm start
```

## Commands

```text
!ping
!waifu
!rimuru
!animequote
!joke
!rules
!tagall
```
